Implement a **full Meta integration** inside the existing application. The goal is to create a completely separate **Meta Analytics** page that connects to Meta/Facebook/Instagram and automatically pulls reporting, lead, campaign, audience, content, messaging, and performance data from Meta APIs.

Do **not** redesign the existing Leads Centre or Exports pages unless integration hooks are required. Create a dedicated Meta reporting module/page that follows the same existing application UI, navigation, authentication, role permissions, dark-blue branding, spacing, cards, typography, and responsive behaviour.

## PRIMARY GOAL

Create a new navigation item called:

**Meta Analytics**

This page must act as an internal Meta Business Suite-style reporting dashboard.

The page must pull real data from connected Meta assets through the appropriate official Meta APIs and display the available reporting metrics inside our own application.

The system must support:

* Facebook Pages
* Instagram Professional/Business accounts
* Meta Lead Ads
* Meta campaigns
* Ad Sets
* Ads
* Instant Forms
* Facebook/Instagram insights
* Video/Reels insights where available
* Messaging/conversation metrics where Meta exposes them
* Lead reporting
* Campaign reporting
* Date-range reporting
* CSV exports
* Historical metric storage
* Period comparisons

Do not use mock data once a Meta account has been connected.

If a specific metric is not available through the current Meta API or required permissions have not been granted, clearly show:

**Metric unavailable through Meta API**

instead of inventing a value.
